DawnTranslate 0.4.0

安装
1. 将 DawnTranslate.app 拖到 Applications（应用程序）。
2. 从“应用程序”打开 DawnTranslate。
3. 在“设置”里填写你自己的模型地址、模型名和 API 密钥，再保存连接。

系统要求
macOS 14 或更新版本。此包适用于 Apple 芯片 Mac（arm64）。
包含本机 Whisper 中英识别模型；无需另装 Python。

会议翻译（Teams / 飞书桌面版）
先用“仅字幕”确认可以识别对方的声音。
双向语音需要 BlackHole 2ch 等虚拟麦克风和耳机，按“连接音频”的说明设置。
Mac 输入保持真实麦克风；会议软件麦克风选择虚拟通道；Mac 与会议软件输出选择耳机。
首次使用可能需要麦克风、屏幕与系统音频录制权限。
英文语音优先本机已安装的增强男声，系统声音不会随此安装包分发。

数据与密钥
安装包不附带任何人的 API 密钥、模型账户、偏好设置、会议录音或聊天记录。
你填写的密钥保存在你自己 Mac 的钥匙串中。
截图与语音识别在本机完成，识别后的文字发送至你配置的模型服务。
模型服务可能收费；系统本机语音合成不新增云端语音费。

版本限制
应用采用本地临时签名，尚未取得 Apple 开发者证书签名及公证。
下载后 macOS 可能要求额外确认来源，部分受管理设备可能不允许运行。
不要关闭系统安全保护；不接受未受信任应用时请从源码构建。
会议语音按句翻译，有延迟；当前保留对方英文原声，中文译声随后播放。
