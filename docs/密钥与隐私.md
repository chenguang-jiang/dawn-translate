# 密钥与隐私

## 安装包不包含个人配置

安装包从 Swift 源码与明确列出的资源重新构建，只包含应用程序、图标、Whisper 可执行程序、公开语音模型及第三方许可文件。

不复制安装者的钥匙串、UserDefaults、`.env`、`.dsh`、浏览器数据、会议录音、翻译草稿或本机开发目录。新 Mac 需自行配置模型服务。

API 密钥通过 macOS Keychain 保存，服务标识为 `local.dawn.translate.ai`。服务地址、模型名称和音频通道保存在本机偏好设置；`AIConfiguration` 不包含密钥字段。地址中的用户名、密码、查询参数及片段会被拒绝。

“导入本机 DeepSeek”是用户主动操作，仅从当前 Mac 的已有配置读取并保存密钥；该配置文件不会进入源码清单或应用资源。

## 文字与声音的处理位置

- 截图取字和音频识别：本机。
- 翻译及邮件生成：你填写的模型接口。开始持续会议翻译后，识别文字会自动发送给该接口。
- 语音合成：macOS 本机声音。
- 内容历史：内存中，退出后清空。导出操作会将所选内容写入你指定的文件。
- 临时录音：私有临时目录，识别完成、取消或正常退出时清理。非正常崩溃后的操作系统临时文件回收不由应用保证。

## 发布前检查

`check-release-secrets.py` 会检查凭据形态、敏感文件名及可选的本机密钥精确匹配。实际密钥只在内存中参与比对，不写入报告、命令行参数或提交。

示例（凭据路径属于本机，不是上传内容）：

```bash
python3 scripts/check-release-secrets.py /path/to/clean-source /path/to/DawnTranslate.app \
  --secrets-file /path/to/local-credentials.yaml
```

`.gitignore` 排除构建输出、安装包、本地凭据、证书及内部验证记录。发布时还应检查 Git 索引中的实际文件，并扫描解压／挂载后的安装包；仅有忽略规则不足以证明没有泄露。

如果密钥曾经被提交，删除文件不能清除旧历史，需要撤销密钥并处理仓库历史。本项目首次发布使用全新独立仓库，不导入个人工作台的旧提交。
